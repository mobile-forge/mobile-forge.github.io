Mobile GUI Agent Adaptation

MobileForge

Annotation-Free Adaptation for Mobile GUI Agents with Hierarchical Feedback-Guided Policy Optimization

Guangyi Liu, Pengxiang Zhao, Gao Wu, Yiwen Yin, Mading Li, Liang Liu, Congxiao Liu, Zhang Qi, Mengyan Wang, Liang Guo, and collaborators

Paper Code Models Data

Core Idea

Turn unlabeled mobile interaction into an adaptation loop.

MobileForge connects environment exploration, automatic task generation, hint-guided rollout, hierarchical critique, and step-level GRPO. The loop adapts open mobile GUI agents without collecting human annotations for each target task.

Method

MobileGym and HiFPO form the adaptation engine.

MobileGym

Exploration, curriculum generation, and critic feedback provide the environment-side loop for mobile GUI adaptation.

HiFPO

Hint-guided multi-attempt rollout and step-level GRPO convert critic feedback into policy improvement.

Results

Higher AndroidWorld pass rates and improved MobileWorld transfer.

Hierarchical Feedback

Outcome feedback, process feedback, and corrective hints.

The critic does not only say whether a trajectory succeeds. It identifies useful and harmful steps, generates evaluation hints, and provides training signals that HiFPO can reuse during later rollout and GRPO optimization.
